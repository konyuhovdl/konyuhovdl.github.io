Family Tree

 "Family Tree" is a program for preserving the history and building a family tree. With its help, you will create a detailed list of family members, add their biographies, photos and videos. The program is easy to learn, has a clear and beautiful interface, while offering powerful tools for creating an expanded family tree. The "Events Calendar" tab allows you to clearly see the days of important family events. You can customize any element of the calendar: fonts, background, month placement and photos.

File Encryptor

 "File Encryptor" - allows you to encrypt both individual files and recursively all files in a folder and in nested folders. Program functions: encryption and decryption of files using the GOST, Blowfish, IDEA, Misty1, Rijndael, Twofish, Cast128, Cast256, RC2, RC5, RC6, DES, TEA methods using a password; encryption and decryption of files using the CHR, BIT method using a key file; selection of one or more encryption methods; creation of a separate encrypted file with the .cip extension; complete deletion of the source file. The program offers two options for saving the file encryption result. The first option is to encrypt the file itself. The second option is to save the encryption result in a new file with the addition of the CIP file extension. When choosing the second option, you can additionally enable the option to delete the source file. The program will first set all bits to zero in the source file and then delete the file, bypassing the recycle bin. After this, it is impossible to restore the information that was in the file.

Cipher Editor

 "Cipher Editor" is a text editor with a built-in encryption function, combining ease of use, reliability and mobility. It is best to store confidential information in an encrypted text file. The "Cipher Editor" program was created for this purpose. You need to enter one password to gain access to all your passwords. Even if all your password files are stolen, they will be USELESS for the thieves. Or, for example, if you lose your flash drive, you will only lose the flash drive, NOT YOUR PASSWORDS. The editor works with UNICODE text, so you can enter any symbols, including hieroglyphs. You can enter information into the editor in the format you are used to.

Password Generator

 "Password Generator" - you need to change your passwords more often. To generate a password or login, you can use the "Password Generator" program. The program will create a password of any length and from any set of characters. Before generating a password, you must enter the password length "Password Length" and select a set of characters (check the boxes) from which the password string will be formed. Press the F2 key or the first button with the mouse to generate the password. The generated password will be displayed in the field. To copy the password to the clipboard, you can press the F5 key or click the second button with the mouse.

Family Events Calendar

 Family Events Calendar - a program for creating beautiful calendars with photos for any year or month. With its help you can create high-quality photo calendars, just select the format and design of the project, add photos. You can add people with photos to the calendar tied to their birthday. Then the calendar will remind you of memorable dates and birthdays of friends and relatives.
